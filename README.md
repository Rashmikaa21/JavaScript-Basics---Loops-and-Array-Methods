# JavaScript Practice – Loops & Array Methods

This repository contains JavaScript practice programs covering:

* `for` loop
* Arrays
* `forEach()`
* `for...of`
* `for...in`
* Objects
* `map()`
* `filter()`
* `reduce()`


## 🎯 Purpose


These exercises help build a strong foundation in JavaScript loops, arrays, objects, and array methods through simple practice problems.
